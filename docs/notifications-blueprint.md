# Notification blueprint (moved)

Since LëtzFuel HA 0.2.0 the notifications are built into the integration; see
[Notifications in the README](../README.md#notifications).

The notifications blueprint, for your own actions and texts, now lives in its
own repository with its own documentation and versions:
[letzfuel-ha-notifications-blueprint](https://github.com/dabo53ck/letzfuel-ha-notifications-blueprint).

To move an existing automation to it, see
[Coming from the blueprint](../README.md#coming-from-the-blueprint).
