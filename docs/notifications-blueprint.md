# Notification blueprint (replaced)

Since LëtzFuel HA 0.2.0 the notifications are built into the integration; add
a recipient, see [Notifications in the README](../README.md#notifications).

For refuel reminders or your own actions on the integration's events, use the
new [LëtzFuel HA Blueprint](https://github.com/dabo53ck/letzfuel-ha-blueprint). See
[Coming from the blueprint](../README.md#coming-from-the-blueprint).
